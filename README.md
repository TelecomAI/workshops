## Workshops
Welcome to the official repository for **Télécom IA** workshops! This repository houses all the materials, slides, and notebook code used during our technical sessions and hands-on labs.

## Overview
Below is a summary of the available workshops:

* **Workshop 1: Fundamentals of Deep Learning & MLP**
  * **Topics covered:** Deep Learning foundations, Multi-Layer Perceptrons (MLP), Perceptrons, and Gradient Descent.
  * **Hands-on Session (TP):** Practical implementation and training on the **MNIST** dataset.

* *(Future workshops will be added here as they take place.)*

## Organisation
To keep each session structured and easy to navigate, **each workshop is hosted on its own dedicated git branch**. 

To explore a specific workshop's code and slides, switch to its corresponding branch using Git:

```bash
git checkout <branch-name>
```
